Featured Project Case Study

WorldWave — Live Radio Worldwide

A focused example of how I turn an idea into a working browser application using JavaScript, DOM events, filtering, and live user interaction.

The Problem

Users need a simple way to explore radio stations from different countries without navigating multiple websites or manually searching station by station.

The Solution

I built an interactive web experience that organizes worldwide stations into a searchable, filterable interface with live playback controls and responsive behavior.

What I Worked On

  • Structured the interface with semantic HTML and responsive CSS.
  • Used JavaScript to manage user interactions, station filtering, search, and playback controls.
  • Organized the code so UI behavior and data-driven actions stay understandable and maintainable.
  • Published the project with GitHub Pages and tested the live site in the browser.

Technology

HTML5CSS3JavaScriptDOMGitGitHub Pages

Engineering Takeaway

This project demonstrates the same habits I use in construction and field operations: break the problem down, organize the workflow, test each part, correct issues, and deliver something people can actually use.
